# 六十億人與五千人之間

Karpathy 在 2026 年 10 月 11 日（美國時間）的 X 貼文，把大眾對 AI 能力的認知落差畫成四層漏斗：約 60 億人幾乎沒碰過 LLM，約 5,000 人用得到公司內部的前沿系統。本導讀整理這個漏斗的四層、他列出的三個成因，並對照漏斗頂端外界已能查證的兩件事：Hugging Face 事件與 OpenAI 公開的數學手稿。

## 200字介紹

Karpathy 估計，全球約 75% 的人幾乎沒接觸過 LLM，約 20% 偶爾用免費版，約 0.2% 在數學與程式領域專業使用前沿模型，只有約 5,000 人能在公司內部使用最前沿的系統。他認為落差由三件事造成：問題的野心大小、能力集中在可驗證且有營收的領域、以及能不能用到。導讀接著對照兩件已公開的事：Hugging Face 在 7 月公布的 agent 入侵時間線，以及 OpenAI 在 10 月公開的數百份數學手稿。兩者都指向 Karpathy 最後的觀察：人類的審查與理解，開始跟不上產出的速度。
