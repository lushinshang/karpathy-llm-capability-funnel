# 六十億人與五千人之間

Karpathy 在 2026 年 10 月 11 日（美國時間）的 X 貼文，把大眾對 AI 能力的認知落差畫成四層漏斗：約 60 億人幾乎沒碰過 LLM，約 5,000 人能在內部使用最前沿的系統。本導讀含十月貼文的中文翻譯、四月貼文的背景、他的依據是什麼，並介紹他本人與其他媒體的報導，對照最內層的 Hugging Face 事件與 OpenAI 數學手稿，以及台灣六份調查與微軟原報告的外部對照。

## 200字介紹

Karpathy 估計，全球約 75% 的人幾乎沒接觸過 LLM，約 20% 偶爾用免費版，約 0.2% 在數學與程式領域專業使用前沿模型，只有約 5,000 人能在公司內部使用最前沿的系統。他認為落差由三件事造成：問題的野心大小、能力集中在可驗證且有營收的領域、以及能不能用到。導讀補上他的依據（時間軸觀察與粗估，沒有引用統計）、最內層的兩個公開例子，以及台灣的外部調查：以「用過」為口徑，台灣高於全球平均，但各調查的每日使用比例差距極大，專業使用前沿 agent 的人數則查無量化資料。
